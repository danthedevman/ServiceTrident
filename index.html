From signal to resolution

Check uptime. Collect signals. Take action.

01 / MONITOR

Websites & web APIs

Run scheduled HTTP/HTTPS checks, track response time and availability, and check page keywords. Monitor authenticated endpoints with Basic, Bearer, or OAuth client credentials.

02 / AGGREGATE

Events in one place

Bring monitor checks and external events into the same workspace. Send normalized signals through the scoped external API, correlate alerts, and triage by service, source, and severity.

03 / RESPOND

Incidents with context

Connect alerts to incidents, assign responders, and coordinate on-call coverage, escalation, tasks, and work notes. Capture root causes and share recovery through a public status page.

Your infrastructure. Your data.

A few commands. Then your first monitor.

Install Git and Docker with Compose, start Docker, and keep port 8090 available. Run these commands in a macOS/Linux shell or Windows PowerShell: 

git clone https://github.com/danthedevman/ServiceTrident.git
cd ServiceTrident
cp .env.example .env
docker compose up -d --build --wait
  1. Open http://127.0.0.1:8090 once startup completes and create an account.
  2. Open Quick Setup on Overview or in Create to add your first service and monitor.
  3. Connect notifications and on-call coverage when you are ready. These steps are optional in Quick Setup.

Docker starts the app, API, workers, scheduler, MongoDB, and Redis. No separate Node.js or database installation is needed. Provider credentials and production HTTPS configuration take additional time.
